# Cloud Engineer Portfolio (React + Vite)

## Run it locally
```
npm install
npm run dev
```
Then open the printed local URL (usually http://localhost:5173).

## Edit your content
Everything on the page is generated from **one file**: `src/data.js`.
Open it and replace the placeholder values (name, role, about text,
skills, certifications, experience, projects, contact links) with your
own. You shouldn't need to touch any component file.

## Build for deployment
```
npm run build
```
This outputs a static site to `dist/` which you can deploy to Vercel,
Netlify, GitHub Pages, or any static host.
